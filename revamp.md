# ALBARMOX — Personal Portfolio Website Revamp

## Project Overview

Redesign my personal portfolio website:

https://www.albarms.my.id/

Create a premium, modern, visually distinctive personal portfolio for **Albar Moerhamsa**, a Software Engineer and Frontend Engineer.

The new visual direction is called:

**PLAYFUL ENGINEERING — Bold, Expressive, and Product-Focused.**

The goal is to transform the existing portfolio from a technical, terminal-inspired developer website into a vibrant, editorial, product-focused portfolio that communicates both engineering expertise and design sensibility.

Use the attached UPFLUENCE website screenshot as the primary visual inspiration. Take inspiration from its layout composition, typography, colors, image collage, whitespace, and visual hierarchy. Do not directly copy its branding, logo, text, or content.

The result should feel like a combination of:
- A modern creative studio website.
- An editorial design portfolio.
- A premium software engineer personal brand.
- A contemporary digital product showcase.

## 1. Brand Identity and Color System

Use the following color palette consistently throughout the website.

**Primary Colors**

- Sky Blue: `#0099FF`
- Cloudy White: `#FDFDFE`
- Amber Red: `#F04A2D`

Note: Use `#F04A2D` as the accent color. It is the corrected value for the originally supplied invalid hexadecimal color.

**Supporting Colors**

- Deep Ink: `#111827`
- Warm Paper: `#F5F2E9`
- Soft Gray: `#E8EDF2`

Color usage:
- Sky Blue: Main hero background, branded highlights, and selected sections.
- Cloudy White: Main background and typography on blue backgrounds.
- Amber Red: Primary CTA buttons and small visual accents.
- Deep Ink: Headlines and body text on light backgrounds.
- Warm Paper: Project and editorial section backgrounds.
- Soft Gray: Borders, dividers, and subtle interface elements.

Avoid excessive gradients, shadows, and unnecessary decorative effects. Use solid colors and generous whitespace.

## 2. Typography System

Typography is one of the most important design elements.

Use these fonts:

**Display Font: Big Shoulders Display**
- Weight: 800–900.
- Use for hero headlines, section headings, and prominent statements.
- All uppercase for major headlines.
- Tall, condensed, bold letterforms.
- Tight line height and slightly negative letter spacing.

**Body Font: Manrope**
- Weight: 400–700.
- Use for paragraphs, navigation, descriptions, buttons, and project information.
- Keep it modern, clean, and highly readable.

**Technical Accent Font: IBM Plex Mono**
- Weight: 400–500.
- Use sparingly for project categories, dates, technology labels, and small metadata.
- Do not use it as the primary typography.

Typography should be expressive and oversized, especially in the hero section. Make the display typography the main visual identity of the website.

## 13. Layout and Responsive Design

Create a high-fidelity desktop and mobile design.

**Desktop**
- Target viewport: 1440px.
- Maximum content width: approximately 1320–1400px.
- Generous horizontal spacing.
- Large expressive typography.
- Asymmetrical editorial grid.
- Large visual project previews.

**Tablet**
- Target viewport: 768px.
- Reduce heading sizes proportionally.
- Preserve image composition where possible.
- Transition multi-column layouts appropriately.

**Mobile**
- Target viewport: 390px.
- Single-column content layout.
- Responsive typography using fluid sizing.
- Simplified hero image collage.
- Horizontal overflow must be avoided.
- Maintain clear CTA visibility.
- Use adequate touch targets.
- Navigation should collapse into a mobile menu.

## 14. Interaction and Motion Direction

## 16. Important Design Restrictions

DO:
- Follow the attached UPFLUENCE screenshot's visual direction.
- Use bold condensed typography.
- Make Sky Blue the dominant brand color.
- Use large project screenshots.
- Create a memorable hero composition.
- Use editorial layouts and generous whitespace.
- Make the portfolio feel personal, confident, and modern.
- Preserve authentic project and professional information.

DO NOT:
- Copy the UPFLUENCE brand identity.
- Create a generic SaaS dashboard.
- Use a dark terminal-inspired visual theme.
- Use excessive monospace typography.
- Use excessive glassmorphism.
- Use too many small cards.
- Use generic stock photos as project screenshots.
- Invent professional experience, testimonials, statistics, or achievements.
- Make the site look like a conventional corporate template.

## Final Creative Direction

The final website should look like a premium creative portfolio with the personality of a modern digital product engineer.

The experience should communicate:

"I don't just write code. I build digital products, solve real problems, and care about the experience behind every pixel."

Prioritize the visual quality of the hero section, expressive typography, distinctive image collage, and project showcase.

Create a cohesive, polished, high-fidelity website design with consistent visual identity across all sections.

Refine the current design to make it more visually distinctive and closer to the attached UPFLUENCE visual reference.

Focus on:
- Making the hero headline significantly larger, bolder, and more condensed.
- Using Big Shoulders Display Black for all major headlines.
- Strengthening the Sky Blue (#0099FF) visual identity.
- Making the image collage more expressive with alternating circular and rounded rectangular shapes.
- Increasing the size and visual prominence of project screenshots.
- Improving whitespace, alignment, and editorial composition.
- Making the overall design feel more premium, memorable, and less like a generic developer portfolio.

Keep the existing content, branding, color palette, and design system consistent. Do not introduce unrelated colors or change the overall creative direction.
